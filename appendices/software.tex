The research software, source files, and supplementary digital material associated with this dissertation are available through the GitHub repositories listed below.

\medskip
\noindent\href{https://github.com/schmampf/dissertation}{\githubicon\ \texttt{schmampf/dissertation}}\par
\noindent LaTeX source of this dissertation.

\medskip
\noindent\href{https://github.com/schmampf/dissertation-supplementary}{\githubicon\ \texttt{schmampf/dissertation-supplementary}}\par
\noindent Supplementary video material, animations, interactive figures, and other digital content accompanying this dissertation will be published in this repository. It serves as the persistent entry point for material that cannot be represented adequately in the printed document.

\medskip
\noindent\href{https://github.com/schmampf/dissertation-figures}{\githubicon\ \texttt{schmampf/dissertation-figures}}\par
\noindent Source code and processing scripts used to generate figures for this dissertation.

\medskip
\noindent\href{https://github.com/schmampf/superconductivity}{\githubicon\ \texttt{schmampf/superconductivity}}\par
\noindent Analysis, simulation, fitting, and visualization tools for superconducting transport experiments.

\medskip
\noindent\href{https://github.com/schmampf/p5control-bluefors-evaluation}{\githubicon\ \texttt{schmampf/p5control-bluefors-evaluation}}\par
\noindent Setup-specific evaluation code for measurements performed with the Bluefors MCBJ experiment.

\medskip
\noindent\href{https://github.com/mawenzy/p5control-bluefors}{\githubicon\ \texttt{mawenzy/p5control-bluefors}}\par
\noindent Setup-specific measurement-control layer for the Bluefors MCBJ experiment, developed primarily by me on top of \texttt{p5control}.

\medskip
\noindent\href{https://github.com/mawenzy/p5control}{\githubicon\ \texttt{mawenzy/p5control}}\par
\noindent Instrument-control and data-acquisition framework developed with Florian Kayatz as part of a project under my supervision.
