    %=========================================================

        No gate modulation is observed for all three cases.

        \singlefitfigure{ssn-set/ssn2-sin}{
            bla
        }{fig:ssn2-set:sin}

        The unbroken device i basically a SIN tunnel barrier Al-AlOx-Cu contact.
        The Spectrum can be fitted with simple SIN BCS Dynes model and reveals.

        \begin{align}
            G_\mathrm{N} = 0.39859(3)\,G_0 &&
            R_\mathrm{N} = \qty{32.379(2)}{\kilo\ohm}          
        \end{align}

        \begin{align}
            \Delta_0 = \qty{195.99(2)}{\micro\electronvolt} &&
            T = \qty{59.5(8)}{\milli\kelvin} &&
            \gamma = \qty{1.48(4)}{\micro\electronvolt}
        \end{align}
        No non-linearities found in normal state.

        If we start pulling the MCBJ apart, I measured i high conductive state of the MCBJ.

        \singlefitfigure{ssn-set/ssn2-dcb}{
            bla
        }{fig:ssn2-set:dcb}
        In the normal conducting State, we observe proper DCB
        If we again asume an effective RC environment, we can make a proper fit of the conductance and the three effective values RC and T
        \begin{align}
            G_\mathrm{N} = 0.37488(3)\,G_0 &&
            R_\mathrm{N} = \qty{34.43(3)}{\kilo\ohm}          
        \end{align}

        \begin{align}
            R_\mathrm{eff} = \qty{0.446(3)}{\kilo\ohm} &&
            C_\mathrm{eff} = \qty{4.36(5)}{\femto\farad} &&
            T_\mathrm{eff} = \qty{77(6)}{\milli\kelvin}
        \end{align}

        \singlefitfigure{ssn-set/ssn2-sin-dcb}{
            bla
        }{fig:ssn2-set:sin-dcb}
        However, the superconducting state reveals a more odd IV.
        Below 0.55 mV it seems as we had a normal SIN BCS Dynes Tunnel Barrier.

        \begin{align}
            G_\mathrm{N} = 0.33657(2)\,G_0 &&
            R_\mathrm{N} = \qty{38.34(2)}{\kilo\ohm}          
        \end{align}

        \begin{align}
            \Delta_0 = \qty{195.94(6)}{\micro\electronvolt} &&
            T = \qty{121(2)}{\milli\kelvin} &&
            \gamma = \qty{0.88(9)}{\micro\electronvolt}
        \end{align} 
        
        However above that threshold we reach a higher conductance. If we use the data abs(V) > 0.6 and the same superconducting parameter as we extracted before, we end up with a different conductance.
        For those parameter we fitted the dIdV.
        \begin{align}
            G_\mathrm{N} = 0.40172(3)\,G_0 &&
            R_\mathrm{N} = \qty{32.13(2)}{\kilo\ohm}          
        \end{align}
        It seems like we have the same conductance as in the non-modified BJ case.
